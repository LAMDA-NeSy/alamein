# Scene animation sources

The setup screen uses local, recolored copies of these Game Icons assets:

- `scene-tank.svg`: `tank.svg` by Lorc
  - Source: https://game-icons.net/1x1/lorc/tank.html
- `scene-airplane.svg`: `airplane.svg` by Skoll
  - Source: https://game-icons.net/1x1/skoll/airplane.html

Both works are available under CC BY 3.0: https://creativecommons.org/licenses/by/3.0/

The local copies remove the source preview background and recolor the silhouettes for the setup screen.
